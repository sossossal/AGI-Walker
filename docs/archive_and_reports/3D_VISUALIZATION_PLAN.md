# 3D Visualization Plan

This archived plan keeps the earlier thinking around 3D-facing visualization surfaces.

## Historical Intent

The main visualization targets were:

- Godot-based simulation scenes
- browser-facing monitoring surfaces
- replay or inspection views for robot state
- richer debugging feedback for control workflows

## What Still Matters

- Visualization should stay tied to real runtime data.
- Demo surfaces should be documented the same way as CLI and MCP workflows.
- If a visualization path is experimental, mark it that way in the docs.

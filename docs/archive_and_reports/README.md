## How To Read These Files

Treat these pages as archive context. They are useful for:

- Understanding previous delivery phases
- Recovering release copy or announcement structure
- Reviewing historical blockers and completion criteria
- Reusing planning language for future cleanup work

If a statement in this folder conflicts with current code or current guides, the current guides win.

# GitHub Update Guide

This archived guide records the typical GitHub-facing updates that accompany a repository cleanup or release.

## Typical Update Targets

- Repository `README`
- Release notes
- Pull request summary
- Issue tracker references for follow-up work

## Recommended Content Order

1. What changed for users
2. Which entry points are now supported
3. What remains experimental or archived
4. Which docs should be read first

## Current Canonical Links

When preparing GitHub-facing copy, prioritize:

- `README.md`
- `docs/CURRENT_STATUS.md`
- `docs/guides/CLI_GUIDE.md`
- `docs/guides/WEB_PANEL_GUIDE.md`
- `docs/mcp.md`

## Archive Note

This guide is a communication template, not a policy document.

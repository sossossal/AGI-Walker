# AGI-Walker GUI 使用指南

## Skills浏览器

可视化的Skills系统管理工具。

### 启动

```bash
python agi_walker/gui/skills_browser.py
```

### 功能特性

#### 1. Skills列表
- 显示所有可用Skills
- 按分类自动排序
- 显示emoji图标
- 鼠标悬停显示详情

#### 2. 搜索功能
- 实时搜索
- 匹配名称/描述/分类
- 即时过滤结果

#### 3. 分类过滤
- 下拉菜单选择分类
- 快速筛选特定类型Skills

#### 4. 详情查看
- Skill基本信息
- 依赖列表
- 完整Markdown文档
- 语法高亮显示

#### 5. 快捷操作
- **打开目录**: 在文件管理器中打开Skill目录
- **查看API**: 显示API参考文档
- **刷新**: 重新加载Skills列表

### 使用流程

#### 场景1: 浏览Skills
1. 启动GUI
2. 查看左侧列表
3. 点击感兴趣的Skill
4. 右侧显示详细信息

#### 场景2: 搜索Skill
1. 在搜索框输入关键词
2. 列表自动过滤
3. 从结果中选择
4. 查看详情

#### 场景3: 按分类筛选
1. 点击分类下拉菜单
2. 选择目标分类
3. 只显示该分类Skills
4. 查看和比较

#### 场景4: 查看文档
1. 选择Skill
2. 右侧显示Markdown文档
3. 滚动查看完整内容
4. 点击"查看API"查看参考

#### 场景5: 打开目录
1. 选择Skill
2. 点击"打开目录"
3. 在文件管理器中查看
4. 访问脚本和资源

### 快捷键

- `Ctrl+F`: 聚焦搜索框
- `F5`: 刷新列表
- `Ctrl+Q`: 退出应用

### 系统要求

- Python 3.8+
- PyQt6
- agi_walker包

### 安装依赖

```bash
pip install PyQt6
```

### 故障排除

#### 问题: GUI无法启动

**原因**: PyQt6未安装

**解决**:
```bash
pip install PyQt6
```

#### 问题: Skills列表为空

**原因**: Skills目录路径不正确

**解决**:
1. 确认在AGI-Walker项目根目录运行
2. 检查 `agi_walker/skills/` 目录存在
3. 使用"刷新"按钮重新加载

#### 问题: 文档显示乱码

**原因**: 编码问题

**解决**:
- 确保SKILL.md文件使用UTF-8编码
- 重新保存文件为UTF-8

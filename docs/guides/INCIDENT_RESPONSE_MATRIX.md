# AGI-Walker Incident Response Matrix

更新日期：`2026-04-13`

本页定义当前工业化交付范围内的最小事件分级、响应时限和升级路径。它用于客户部署、验收和运维交接，不用于替代客户自己的值班制度。

## 事件等级

### P1

定义：

- Web Panel 无法启动或无法访问
- 数据库损坏或无法读取
- release / deployment 使用了错误版本且影响生产可用性
- 分布式或 Godot 控制链路导致核心演示/交付环境不可用

目标：

- 首次响应：`30 分钟内`
- 升级决策：`1 小时内`
- 恢复或降级方案：`4 小时内`

### P2

定义：

- workflow 运行异常，但系统仍可部分使用
- archive / runs 浏览异常
- backup 或 restore 演练失败
- 漏洞扫描或 security posture 报告进入 `blocked`

目标：

- 首次响应：`4 小时内`
- 处置计划：`1 个工作日内`

### P3

定义：

- 文档错误
- 非关键 smoke 失败
- 可规避的 UI/文案问题
- 未影响当前部署的配置告警

目标：

- 首次响应：`2 个工作日内`
- 修复计划：`1 周内`

## 升级路径

当前最小升级链路：

1. 值班/维护人确认等级
2. 如果涉及 release 或配置变更，关联对应 `release_manifest`
3. 如果涉及部署，关联部署 actor、时间和 env 文件版本
4. 如果涉及数据安全或恢复，关联备份/恢复报告

## 当前要求

每个 P1/P2 事件至少记录：

- 事件时间
- actor
- 影响范围
- 当前版本 / release manifest
- 当前配置或部署路径
- 临时缓解方案
- 最终修复动作

## 当前不声明的能力

当前不把以下内容当成已交付能力：

- 7x24 托管值班
- 第三方 Pager 平台集成
- 自动工单系统
- 多区域灾备编排

如果客户需要这些能力，必须作为实施或平台扩展项单独定义。
